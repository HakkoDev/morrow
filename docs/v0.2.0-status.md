# Morrow 0.2.0: implementation and release gates

The 0.2.0 source is under active development. It is not yet a verified public release.

## Source implemented, awaiting native QA

- Unified cached Inbox across accounts, account-scoped message actions and detail queries, favorite folders and cached unread counts.
- SQLite FTS5 search indexing with triggers for insert, edit and delete, including cache migration.
- Message-ID / References / In-Reply-To-based thread grouping and reply headers.
- SQLite local draft autosave, recovery and successful-send cleanup.
- Existing 60-second server-side polling fallback.
- GNU GPLv3 license text and package metadata (`GPL-3.0-only`), plus license distribution in release workflow.

## Not complete

- IMAP IDLE, reconnect/backoff and notification-specific sync behavior.
- Gmail and Microsoft OAuth2 browser flows and credential renewal.
- Native desktop notifications, unread badges and tray controls.
- Rich-text composer, inline images, remote IMAP Drafts synchronization and comprehensive draft crash recovery.
- Advanced search filters (dates, folders, sender field), indexing progress and large-mailbox performance measurements.
- Multi-identity sending from one mailbox account.

## Required checks before the GitHub release

Run `bun install --frozen-lockfile`, `bun run biome:check`, `bun run typecheck`, `bun run test:source`,
`bun run build`, `cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check`,
`cargo test --manifest-path src-tauri/Cargo.toml`, and
`cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets`.

Then run the real Tauri Windows NSIS and Linux AppImage/DEB builds. Smoke-test two real IMAP/SMTP accounts,
offline cache migration from 0.1.7, unified mailbox account isolation, FTS updates, draft recovery,
thread navigation, signed auto-update, and GPL LICENSE availability in release assets.

Keep the Plane module In Progress and individual source-implemented items In Review until verified.
