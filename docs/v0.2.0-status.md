# v0.2.0 development status

The cumulative source archives through shadcn standardization are integrated with the repository's previously validated fixes. Version remains **0.2.0**. Local validation is not a claim of live-provider or installed-desktop compatibility; nothing is pushed or published by this review.

## Implemented

- Account-scoped unified Inbox, favorite folders, cached unread counts and conversation navigation.
- Incremental SQLite FTS5 offline search, including `from:`, `in:`, `after:` and `before:`. Folder searches retain account/folder scope; unified search spans accounts. Dates use UTC and bound SQL parameters.
- Recoverable SQLite drafts, serialized autosaves (including drafts cleared to empty), rich-text editing and plain-text MIME alternatives.
- Up to five explicitly selected PNG/JPEG/GIF/WebP inline images, 2 MiB each, with native base64/content validation and CID MIME conversion. Pasted/dropped foreign HTML cannot bypass outgoing sanitization.
- Bounded, cancellable IMAP IDLE with polling fallback; UIDVALIDITY-aware new-mail counting; opt-in private notifications with per-account muting; tray/unread indicators.
- Google/Microsoft public-client OAuth2 with browser PKCE, validated ephemeral loopback callbacks, Rust-only bounded HTTPS token exchange, OS-vault token storage and serialized refresh. Bearer authentication is restricted to official encrypted provider endpoints.
- SQLite schema v6 and conservative bidirectional synchronization of **Morrow-owned** drafts every three minutes, with debounced uploads, revision/hash baselines, conflict recovery copies and explicit resolution. Remote deletion retains local recovery. Mutations require UIDPLUS and exact ownership/content checks.
- Explicit read-only discovery/import of external provider drafts as independent UUID copies. Supported attachments persist under application data; supported CID images become data URLs. Original server drafts are never altered by import. Saved drafts support Bcc and empty recipient lists; SMTP sends still require recipients.
- Renewable per-window editor leases with crash expiration. Reopening a saved draft focuses its existing account-scoped composer rather than creating competing autosavers. Automatic/manual uploads and send operations share an in-flight guard.
- Shared Radix-backed shadcn controls for menus, dialogs, selects, tabs and toggles, plus a manual reviewable lockfile-refresh workflow.

## Local verification

- Frozen Bun installation and Bun/Cargo dependency alignment passed.
- Biome, full TypeScript checking and production frontend build passed. Vite reports a non-blocking bundle-size warning.
- All **83 JavaScript source/runtime tests** pass, including real Radix dialog close/Escape/focus restoration, keyboard dropdown/select actions, checkbox/switch changes and tab switching, plus composer recovery, account-scoped composer reuse, upload/send exclusion, sanitization and notification races.
- All **35 Rust tests** pass, covering migrations/search isolation, protocol IDLE behavior, MIME construction, inline-image validation, OAuth callbacks/token validation, draft editor leases and external import. Strict Clippy and rustfmt pass.
- Final unsigned and temporary-QA-signed Windows NSIS builds pass, including updater signature generation. Release configuration is restored after the signing test. Temporary QA signing keys are not production credentials or trusted update artifacts.
- Version alignment, standalone SQLite FTS5 smoke checks, actionlint and workflow YAML/Bash syntax checks pass. Linux/macOS packaging and installed-desktop behavior are not verified by these checks.

## Remaining external acceptance checks

- Register Google/Microsoft desktop applications and test consent, XOAUTH2, refresh rotation and provider policies with live accounts.
- Exercise live IMAP synchronization across two Morrow instances: offline edits, conflicts, APPEND disconnects, UIDVALIDITY changes, folder limits, remote removal and UIDPLUS absence. Validate external imports with real Gmail/Outlook/Apple Mail MIME.
- Install and exercise Windows notification permissions, tray/taskbar indicators and native multi-window behavior. DOM interaction tests do not establish visual layout or OS integration.
- Build and install Linux/macOS packages and verify supported native badge behavior. Production signing and release/update publication are separate checks.
- Automatic edit-in-place synchronization of foreign-provider drafts and lossless attachment/CID-aware download of Morrow-owned drafts remain unsupported. Unknown or ambiguous MIME is retained on the server rather than imported lossily. Scans deliberately refuse oversized folders (500 total messages or 100 owned drafts).

Back up the cache before opening a schema-v6 build; older binaries cannot open the upgraded database. See `docs/v0.2.0-smoke-tests.md` for the manual acceptance matrix.
